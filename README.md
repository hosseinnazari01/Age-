# 🎂 محاسبه‌گر سن با زبان پایتون

این پروژه یک برنامه ساده برای محاسبه سن است که با استفاده از زبان برنامه‌نویسی Python طراحی و پیاده‌سازی شده است.

در این برنامه، کاربر سال تولد خود را وارد می‌کند و برنامه با استفاده از سال جاری (۱۴۰۵)، سن تقریبی او را محاسبه و نمایش می‌دهد.

## 🚀 قابلیت‌های برنامه

- دریافت سال تولد از کاربر
- محاسبه سن تقریبی
- نمایش نتیجه محاسبه بر اساس سال ۱۴۰۵

## 🛠️ مفاهیم استفاده‌شده

- متغیرها (Variables)
- دریافت ورودی با `input()`
- تبدیل داده به عدد صحیح با `int()`
- عملگر تفریق (`-`)
- نمایش خروجی با `print()`

## ⚙️ نحوه عملکرد برنامه

ابتدا برنامه سال تولد را از کاربر دریافت می‌کند. سپس سال تولد از عدد ۱۴۰۵ کم می‌شود و نتیجه به‌عنوان سن تقریبی کاربر نمایش داده می‌شود.

## 🎯 هدف از ساخت پروژه
